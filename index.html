  3. , observe
  4. gt ←(g, gt−1, O(Xt))

LLM-to-Flow Distillation (LFD) iteratively adapts a pretrained scientific generator (the student) with Direct Preference Optimization (DPO) on preferences induced by an LLM teacher.

Because the pretrained model may rarely generate samples aligned with the natural-language goal g, the teacher also proposes intermediate subgoals that are from the currently generated samples.

At each round t, the teacher uses observables O(Xt) of the current sample batch Xt to propose an attainable subgoal gt. Then, for each candidate, it returns a positive, negative, or abstain judgment ℓt(xi) ∈ {+, −, ∅}. Excluding abstentions, the positive and negative sets induce the dataset:

Pt = {xi ∈ Xt : ℓt(xi) = +},
Nt = {xi ∈ Xt : ℓt(xi) = −}.

All positive–negative pairs in Dt = Pt × Nt train the student, using the current generator pθₜ as a frozen DPO reference. We minimize the DPO loss, which favors positive over negative candidates relative to this reference:

Δtθ = log[pθ(x⁺)/pθₜ(x⁺)] − log[pθ(x⁻)/pθₜ(x⁻)], 　 Lt(θ, Dt) = −EDₜ log σ(βΔtθ).

Here, σ is the logistic function and β > 0 controls regularization. Starting from θt, optimizer steps yield θt+1; we then draw fresh samples and repeat.

A design-space view

A goal g defines a target region Ωg in design space. When that region is rarely reached, LFD learns through attainable subgoals that tighten as the generator improves:

Ωg₀ → Ωg₁ → ⋯ → Ωg(T−1) → Ωg

Each Ωgₜ contains designs satisfying gt. The final goal stays fixed.

Resampling after every update keeps the teacher’s feedback tied to what the generator can currently produce.

The observables O(Xt) describe the current sample batch to the teacher. They provide evidence about the part of the design space the student can reach, informing the next subgoal.

The choice of observables depends on the scientific domain.

Use the original goal, previous subgoal, and current sample observables to propose an attainable relaxation.

gt ← SetGoal(g, gt−1, O(Xt))

Accept the subgoal only when the teacher identifies enough positive and negative candidates for a useful learning signal. As the student improves, the teacher tightens the goal online.

For each candidate, request a positive, negative, or abstain judgment under the current subgoal, with a rationale and sources of uncertainty:

ℓt(x) ∈ {+, −, ∅}

The positive set Pt and negative set Nt induce preference pairs:

Dt = Pt × Nt

In the experiments, two independent judgment passes must agree on a positive or negative label. Abstained and inconsistent candidates are excluded from preference training. The feedback is categorical; uncertainty is described in words.

For a preference pair (x⁺, x⁻) ∼ Dt, measure how its relative likelihood changes from the current generator:

Δtθ = log[pθ(x⁺)/pθₜ(x⁺)] − log[pθ(x⁻)/pθₜ(x⁻)]

Minimize the teacher-induced DPO objective:

Lt(θ, Dt) = −EDₜ log σ(βΔtθ)

σ is the logistic function; β > 0 controls regularization. Keep the reference pθₜ fixed during this round.

θt → optimize the surrogate loss → θt+1

Start from θt and take optimizer steps on the denoising-loss surrogate, since terminal log-densities are intractable. Return the updated parameters, then resample for the next round.
